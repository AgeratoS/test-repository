# КРУЧУ-ВЕРЧУ — сайт-визитка

Mobile-first лендинг прачечной самообслуживания на [Next.js](https://nextjs.org).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
npm start
```

## Настройка контента

Все тексты, цены и контакты — в файле `src/data/content.ts`:

- телефон и адрес
- режим работы
- услуги и цены
- ссылка на карту

## Стек

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
